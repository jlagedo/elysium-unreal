# Original project-authored Unreal content

This is the only tracked namespace for original `.uasset` / `.umap` packages. Unreal mounts it as
`/Game/ElysiumAuthored/**`; package files use Git LFS.

Allowed content is independently authored for this project: camera profiles, curves, shakes,
Blueprint helpers, Level Sequences, and other original remaster assets. Do not copy, convert,
reconstruct, or hard-reference game-derived packages, maps, transforms, timings, scripts, or art
here. Generated products stay under `/Game/ElysiumGenerated/**` or `/ElysiumBaked/**` and
remain ignored.

The complete boundary is `Content/CLAUDE.md` and `docs/operations/repository.md`.
