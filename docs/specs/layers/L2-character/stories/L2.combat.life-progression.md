# Life-taking progression

Layer L2 · `L2.combat.life-progression` · size M · 3 rows, 287 bytes of retail code

**Goal.** 0x101c2ab0 reads the damage-info byte forwarded into life-taking; 0x1032c580 handles the event and 0x103f9160 reloads the kill countdown and increments the capped progression field.

**Order.** The attacker receives Event_TookLife only after the damage path commits a kill.
