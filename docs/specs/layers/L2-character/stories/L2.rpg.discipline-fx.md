# Discipline sound and particle data

Layer L2 · `L2.rpg.discipline-fx` · size L · 9 rows, 1896 bytes of retail code

**Goal.** Reproduce discipline sound, particle, projectile, copy and attachment payload handling at 0x101dbe30, 0x101dc5a0, 0x101dcc80, 0x101dcf10, 0x101dce30, 0x101dc410, 0x101dcc10, 0x101dd510 and 0x102027a0. Keep retail payload names and attachment data through load and use.

**Order.** The discipline FX records are loaded from RPG data and must be available before the main RPG bootstrap runs.
