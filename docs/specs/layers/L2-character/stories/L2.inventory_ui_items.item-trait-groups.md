# Item trait group lifecycle

Layer L2 · `L2.inventory_ui_items.item-trait-groups` · size M · 3 rows, 267 bytes of retail code

**Goal.** At 0x102562b0 and 0x10256300, an item's record trait group is applied to or removed from its owner. At 0x10335ea0, unwield removes the group's effects for a non-null item and refreshes the character before returning.

**Order.** Implement the group operations before Inventory_Unwield, which calls removal.
