# Feat and trait effect catalogue

Layer L2 · `L2.rpg.feat-effect-catalog` · size M · 5 rows, 1476 bytes of retail code

**Goal.** Reproduce feat metadata and TraitEffects parsing and category lookup at 0x101e50b0, 0x101e4fe0, 0x101f6a30, 0x101f81c0 and 0x101f8410. Preserve each loaded effect’s category and source data.

**Order.** Effect records need string and stat-value identity before they can be parsed and resolved.

## Rows

- `0x101e4fe0` Global::FUN_101e4fe0 (155 B, 108 maps, partial) — Loads feat display name, InternalName, HelpText, and the Disabled flag. Port lacks: The feat loader retains InternalName and Name, but FElysiumFeat has no HelpText or Disabled field. Similar stat fields belong to a different table.
- `0x101e50b0` Global::FUN_101e50b0 (832 B, 108 maps, partial) — Loads feat MaxValue, sequential Base/Automatic/Display2nd trait references, PC/NPC weighting-table references, and associated rule data. Port lacks: MaxValue, Base, Automatic, weight names, and nested tables are loaded. Display2nd references are explicitly omitted because no shipped feat authors them.
- `0x101f6a30` Global::FUN_101f6a30 (265 B, 108 maps, partial) — Decode a trait-effect operator and operand, resolving named Value operands or converting other named operands to a boolean. Port lacks: Numeric operators and named Value operands are supported. Non-Value named operands incorrectly fall through to atoi instead of the retail string-handle boolean branch; operator case/leading-space matc
- `0x101f8410` Global::FUN_101f8410 (65 B, 108 maps, open) — Find the first case-insensitive category-name match and return its index, or -1. Port lacks: The trait-effect loader stores category names directly; no equivalent category-index lookup or first-match handling was found.
- `0x101f81c0` Global::FUN_101f81c0 (159 B, 108 maps, partial) — Count TraitEffects files and load sequential TraitEffects%03d.txt effect-category files. Port lacks: Effect categories, groups, and records are loaded, but only traiteffects000.txt; counted sequential-file loading is missing.
