# Inventory section IDs

Layer L2 · `L2.rpg.inventory-sections` · size S · 2 rows, 667 bytes of retail code

**Goal.** Reproduce inventory section initialization and lookup at 0x101eabd0 and 0x101ead30. Retail order is None, Weapon_Melee, Weapon_Ranged, Weapon_Thrown, Armor, Generic, Powerups, Hidden, with indices 0 through 7.

**Order.** Section names and IDs are shared by inventory and equipment loaders.

## Rows

- `0x101eabd0` Global::FUN_101eabd0 (92 B, 108 maps, partial) — Loads an inventory section's InternalName and display name, setting its displayed flag when IsDisplayed is nonzero. Port lacks: Compiled section enums, names, and browseability reproduce the fixed catalog. No InventorySection record parser carries authored InternalName, Name, and IsDisplayed values.
- `0x101ead30` Global::FUN_101ead30 (575 B, 108 maps, partial) — Reset and load the inventory-section registry, including ordered IDs, names, internal names, and IsDisplayed flags. Port lacks: A compile-time mirror carries section indices, labels, and visibility, but no loader reproduces the authored InventorySections registry or reload behavior.

## Records

- `l2_inventory_sections` (arena): At startup, enumerate all inventory sections and query each ID plus an unknown name; observe the exact retail order, indices and fallback before inventory is populated. Needs: NEW: inventory_sections
