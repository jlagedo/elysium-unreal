# Quest index lookup

Layer L2 · `L2.inventory_ui_items.quest-index-fallback` · size S · 4 rows, 577 bytes of retail code

**Goal.** At 0x10221be0 and 0x10221ca0, the journal rejects negative and out-of-range quest and completion indices. At 0x10221b10 and 0x10221e50, invalid getters warn and return the first record rather than null.

**Order.** The lookup contract consumes the quest and completion records produced by quest-catalogue-load; each validity check precedes its getter.
