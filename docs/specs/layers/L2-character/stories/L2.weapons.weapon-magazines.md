# Indexed magazine readers

Layer L2 · `L2.weapons.weapon-magazines` · size S · 2 rows, 65 bytes of retail code

**Goal.** Read magazine `Size` by index and define magazine presence as `Size != -1`, preserving the secondary bank (`0x10251e40`, `0x10251ec0`).

**Order.** Both readers consume the parsed magazine records; the presence predicate calls the indexed size reader.

## Rows

- `0x10251e40` CBaseCombatWeapon::FUN_10251e40 (39 B, 61 maps, partial) — Read the indexed magazine Size from weapon-data +0x2668 + index*0x1093c. Port lacks: Primary capacity is folded into MagazineSize and its caller reads. The second indexed magazine record is not represented.
- `0x10251ec0` CBaseCombatWeapon::FUN_10251ec0 (26 B, 61 maps, partial) — Report whether the indexed magazine's weapon-data Size is different from -1. Port lacks: Inventory insertion uses the primary Size != -1 test. Reload callers instead require Size > 0, and the secondary magazine is explicitly absent.

## Records

- `l2_weapon_magazine_banks` (arena): Load a weapon with two magazine records, including `Size` values of `-1`, zero and positive; after load, verify each indexed size and the exact `Size != -1` result before reload or insertion. Needs: NEW: indexed magazine data probe
