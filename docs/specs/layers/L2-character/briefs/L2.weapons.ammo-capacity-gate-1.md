# Brief L2.weapons.ammo-capacity-gate-1 — Ammo index and capacity gate

Layer L2 · story `L2.weapons.ammo-capacity-gate` · slice 1 of 1 · **ready**

## Goal

The name and capacity readers supply the strict reserve comparison that autopickup uses. The story: Resolve ammo names case-insensitively, return indexed `MaxCarry`, and admit autopickup only for a valid index whose reserve is below capacity (`0x104274b0`, `0x10427620`, `0x10128370`, `0x10336000`).
