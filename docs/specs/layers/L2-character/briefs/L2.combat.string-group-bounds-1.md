# Brief L2.combat.string-group-bounds-1 — String group bounds

Layer L2 · story `L2.combat.string-group-bounds` · slice 1 of 1 · **ready**

## Goal

The group lookup must use the completed per-group bounds policy. The story: 0x10202ac0 validates a string-row index under the group's clamp policy; 0x102030a0 resolves a group ID and returns its value or an empty string.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x10202ac0` Global::FUN_10202ac0 (63 B, 108 maps, partial) — Validate a string-row index, optionally clamping negative and excessive indices to the endpoints. Port lacks: String lookup rejects invalid indices, carrying the nonclamping arm. It does not implement the clamping arm or preserve a per-group clamping flag.
- `0x102030a0` Global::FUN_102030a0 (65 B, 108 maps, partial) — Find a string group by ID and return its indexed value through the group's bounds policy, or an empty string. Port lacks: Named group and indexed string lookup exist. String groups do not preserve the retail clamping policy, so out-of-range clamped lookups return the fallback instead of an endpoint.
