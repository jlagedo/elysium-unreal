# Base entity perception defaults

Layer L0 · `L0.entity_core.base-perception` · size S · 4 rows, 267 bytes of retail code

**Goal.** At 0x1009f2c0, 0x10026610, 0x10026630, and 0x100ad6e0, the base entity returns WorldSpaceCenter as BodyTarget and the retail defaults 1.0, 1.0, and 128 for stealth scalar, stealth cone, and illumination.

**Order.** These are the base-class values queried by higher-level targeting and visibility code.

## Rows

- `0x1009f2c0` CBaseEntity::BodyTarget (134 B, 108 maps, open) — Return the entity's virtual WorldSpaceCenter as its body target. Port lacks: The base BodyTarget returns a zero vector instead of dispatching WorldSpaceCenter. Player and NPC overrides implement different retail bodies.
- `0x10026610` CBaseEntity::GetStealthVisionScalar (7 B, 108 maps, open) — Return the base stealth vision scalar constant, 1.0. Port lacks: The base implementation is a tallying stub returning 0.0, rather than retail's 1.0. NPC overrides are different retail bodies.
- `0x10026630` CBaseEntity::GetStealthVisionCone (7 B, 108 maps, open) — Return the base stealth vision cone scalar constant, 1.0. Port lacks: The base implementation is a tallying stub returning 0.0, rather than retail's 1.0. NPC and player overrides do not carry this base default.
- `0x100ad6e0` CBaseEntity::Illumination (119 B, 108 maps, open) — Return the constant illumination value 128. Port lacks: The matching slot logs a stub and returns zero instead of 128.
