# KeyValues lexer

Layer L0 · `L0.audio.keyvalues-lexer` · size S · 3 rows, 371 bytes of retail code

**Goal.** At 0x1023eff0, 0x102473e0 and 0x10247280, build punctuation membership tables and tokenize whitespace, comments, quoted strings, escapes and configurable punctuation while returning cursor and quote status.

**Order.** The membership-table builder and one-time table initializer are callees of the tokenizer; build them first for both KeyValues readers.

## Rows

- `0x1023eff0` Global::FUN_1023eff0 (54 B, 108 maps, open) — Clear a 256-byte membership table and mark each character supplied in a delimiter string. Port lacks: No equivalent arbitrary character-set builder exists; the tokenizer hardcodes brace comparisons.
- `0x102473e0` Global::FUN_102473e0 (50 B, 108 maps, partial) — Initialize two punctuation membership tables once, differing in whether colon is a delimiter. Port lacks: Brace delimiter recognition is folded into direct comparisons. The remaining punctuation and alternate colon mode are absent.
- `0x10247280` Global::FUN_10247280 (267 B, 108 maps, partial) — Tokenize whitespace, line/block comments, quoted strings with escaped quotes, and configurable punctuation; return the next cursor and quote flag. Port lacks: Handles whitespace, line comments, braces, multiline quotes and escaped quotes. Omits block comments, parentheses/apostrophe delimiters, selectable colon handling, and quote-status output.
