# Sound record lookup

Layer L0 · `L0.sound_list.sound-record-lookup` · size M · 1 rows, 157 bytes of retail code

**Goal.** Preserve `CSoundEnt::SoundPointerForIndex` (`0x101bb150`): indices 0–63 identify stable
sound records while the pool exists; absent pool or invalid index returns null, with retail's
invalid-index diagnostic condition. The Source offset/stride describes the oracle layout, not
required native addresses. Actual admission, retention and pool lifetime are D05 G1 contracts.

**Execution correction (2026-10-11):** lookup/expiry belongs to G1; the appended whole audio bake
(slice 3) belongs to D04 A1; saved pending stimuli (slice 4) belongs to G2. L4 owns listening and
consumer state. The two lookup records alone cannot close those additional requirements.

**Order.** The player producer resolves the index after `ClientSoundIndex`; the lookup also serves NPC hearing, which reads sound records directly.
