# Sound record lookup

Layer L0 · `L0.sound_list.sound-record-lookup` · size M · 1 rows, 157 bytes of retail code

**Goal.** `CSoundEnt::SoundPointerForIndex` (`0x101bb150`) returns `pool + 0x464 + index * 0x2c` for indices 0–63 when the global pool exists. A missing pool or invalid index returns null; an invalid index with a live pool also takes the `DevMsg` path.

**Order.** The player producer resolves the index after `ClientSoundIndex`; the lookup also serves NPC hearing, which reads sound records directly.

## Rows

- `0x101bb150` CSoundEnt::SoundPointerForIndex (157 B, 108 maps, open) — Return the global sound pool's record at index 0–63 (base +0x464, stride 0x2c); return null if the pool is absent or the index invalid. Port lacks: The port uses a 128-record retention bus accessed through serial cursors. No equivalent bounded lookup into retail's 64-slot sound pool was found. References show the alternative implementation.
