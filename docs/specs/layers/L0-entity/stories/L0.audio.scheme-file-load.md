Layer L0 · `L0.audio.scheme-file-load` · size M · 3 rows, 680 bytes of retail code

**Goal.** At 0x102482b0, 0x10248510 and 0x102480f0, load or reuse a KeyValues file and populate named top-level trees with ordered leaves whose unquoted values retain integer or float types.
