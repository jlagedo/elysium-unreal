# Sound script resolution

Layer L0 · `L0.audio.sound-script-resolve` · size M · 4 rows, 1262 bytes of retail code

**Goal.** At 0x1012f700, 0x101b3240 and 0x101b33f0, evaluate fixed or random parameter intervals, prefer category-matching waves with all-wave fallback, and validate the resolved sample.

**Order.** The resolver calls the interval evaluator and wave selector and consumes the initialized descriptor and parsed channel.

Port lacks: Port comments explicitly state that no game_sounds script table is resolved. Sound-script emission only records names; baked audio-path lookup does not implement this definition lookup.
