# Client sound slot index

Layer L0 · `L0.sound_list.client-sound-index` · size S · 1 rows, 107 bytes of retail code

**Goal.** `CSoundEnt::ClientSoundIndex` (`0x101bb220`) calls the engine index interface at `+0x8c` for the supplied entity and returns `IndexOfEdict - 1`; edict 1 maps to reserved sound slot 0. `CBasePlayer::UpdatePlayerSound` (`0x1016b480`) uses this as the first step in addressing its reserved record.

**Order.** First in the player sound lookup path: `UpdatePlayerSound` obtains the client index before resolving its record.
