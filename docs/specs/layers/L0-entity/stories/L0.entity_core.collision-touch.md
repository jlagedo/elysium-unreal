# Solid changes and untouch checks

Layer L0 · `L0.entity_core.collision-touch` · size L · 5 rows, 598 bytes of retail code

**Goal.** At 0x100dc300, 0x100dc580, 0x100dc430, 0x100b11d0, and 0x100f8e20, collision state changes invalidate and refresh the required state; a non-solid non-trigger entity that touches something queues an untouch check once, using the EFlags bit and generation rules.

**Order.** SetCheckUntouch writes the shared EFlags word; entity construction calls the collision initializer and solid setter.
