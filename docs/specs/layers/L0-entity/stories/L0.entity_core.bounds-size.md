# Collision bounds and size

Layer L0 · `L0.entity_core.bounds-size` · size M · 2 rows, 239 bytes of retail code

**Goal.** At 0x100dc770 and 0x100b1960, retail stores collision mins and maxs, derives the half-diagonal radius, invalidates cached bounds, and returns the entity's size vector.

**Order.** This is the collision geometry provider used by construction and spatial queries.
