# Entity touch lifecycle

Layer L0 · `L0.physics.touch-lifecycle` · size L · 9 rows, 1859 bytes of retail code

**Goal.** Keep the collision trace and reciprocal touching list at `0x1003e2e0`, the live/deletion gates and StartTouch-before-Touch order at `0x1003db80` and `0x1003daa0`, and parent forwarding through `0x100a49d0`, `0x100a4af0`, and `0x100a4c20`.

**Order.** Touch routing consumes entity traces, parent links, and trigger bounds; relink and movement stories use this lifecycle.
