# Movement vector primitives

Layer L0 · `L0.physics.motion-primitives` · size M · 3 rows, 628 bytes of retail code

**Goal.** Preserve the exact vector equality gate (`0x1003b850`), retail small-component zeroing and blocked bits (`0x1003ef00`), and gravity-scaled trapezoidal displacement with base velocity (`0x1003ed80`).

**Order.** These leaf calculations are reused by bump movement, STEP, fly, toss, and parented movement.

## Rows

- `0x1003b850` Global::FUN_1003b850 (54 B, 108 maps, open) — Return whether two three-component float vectors are exactly equal. Port lacks: No folded equivalent found in the listed STEP/TOSS paths. STEP record synchronization uses a tolerance comparison; retail's exact velocity/base-velocity zero gates are absent.
- `0x1003ef00` CBaseEntity::PhysicsClipVelocity (280 B, 108 maps, partial) — Project velocity off a collision plane using overbounce, zero small components and return floor/wall blocked bits. Port lacks: ClipVelocity carries projection, overbounce and blocked bits. It omits retail's small-component zeroing and adds a repeated inward-velocity correction instead.
- `0x1003ed80` CBaseEntity::PhysicsAddGravityMove (294 B, 108 maps, open) — Apply scaled gravity to vertical velocity and compute trapezoidal displacement including base velocity, then validate velocity. Port lacks: Player half-gravity helpers and UE NPC gravity exist, but no entity helper reproduces this displacement calculation and base-velocity contribution.
