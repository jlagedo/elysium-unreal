# KeyValues lookup and mutation

Layer L0 · `L0.audio.keyvalues-access` · size M · 4 rows, 396 bytes of retail code

**Goal.** At 0x10248900, 0x10248bb0, 0x10248cd0 and 0x102490e0, find the first case-insensitive child through fallback links, optionally create it, read typed numeric values and write converted string values back.

**Order.** GetString and GetInt call the lookup; GetString can call the setter when converting a typed value. Build the parsed tree first.
