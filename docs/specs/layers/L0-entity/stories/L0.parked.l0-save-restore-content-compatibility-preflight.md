# Validate a native save before replacing the run

Layer L0 · `L0.parked.l0-save-restore-content-compatibility-preflight` · D11 S3

**Scope correction, 2026-10-11.** The filename is retained for traceability. This is current-build
native save validation, not retail importing, old-version compatibility or content migration.

**Goal.** Validate the native envelope/schema and required L0 references/definitions before
replacing the active run. Retain existing valid checks and the restored identity ordering
anchored by `0x101a2e40`. Reject an unsupported or malformed native snapshot safely. Do not add
an all-corpus fingerprint system merely because the old importer brief requested one.

**Order.** After native block/identity/storage services exist, before S3 exposes a load. Each
higher layer later validates its own quest, schedule and other state through the same barrier.
L0 does not implement those higher-layer validators or wait for their runtime behavior.
