# Pushed entity transaction core / Rotational pusher transaction

Layer L0 · `L0.physics.pushed-entity-transaction` · size L · 15 rows, 2650 bytes of retail code

**Goal.** Build pusher hierarchy snapshots and blocker lists, suppress and restore pusher collision membership, speculatively check candidates, then commit trigger/shadow work or roll origins back (`0x10035f00`–`0x100379e0`). Integrate root angular velocity, choose pushed-entity reference points and player corners, speculatively check rotational displacement, then apply angle or player-yaw corrections (`0x100360a0`, `0x10037c10`, `0x10036900`, `0x10036bd0`, `0x10037e90`, `0x100389e0`).

**Order.** Linear and rotational pushes share this snapshot, blocker, rollback, and completion machinery.
