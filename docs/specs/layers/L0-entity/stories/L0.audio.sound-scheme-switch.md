# SoundScheme activation and track switching

Layer L0 · `L0.audio.sound-scheme-switch` · size L · 5 rows, 1007 bytes of retail code

**Goal.** At 0x1022a300 and 0x1022b590, register a scheme and, when enabled, clamp its fade duration, guard repeated activation, disable other schemes and schedule thinking; 0x10229270, 0x10229430 and 0x10229550 prune handles, configure four tracks, reuse matching filenames and retire outgoing tracks in retail order.

**Order.** Scheme activation consumes the parsed track data and calls 0x10229270; that manager routine calls 0x10229430, which retires tracks through 0x10229550.
