# Change timer refire time

Layer L0 · `L0.entity_io.timer-refire` · size M · 1 rows, 74 bytes of retail code

**Goal.** Port `vampire.dll 0x101318e0`: read a float or zero, clamp to the retail minimum, and rearm only when the stored value changes.

**Order.** A changed value calls the timer-arm routine; unchanged and disabled cases must not move the pending deadline.
