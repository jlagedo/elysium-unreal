# Map entity text and parent ordering

Layer L0 · `L0.entity_core.map-ordering` · size M · 3 rows, 476 bytes of retail code

**Goal.** At 0x10136a30, 0x10136910, and 0x101368a0, retail extracts the first exact key token, resolves parent names recursively with self and cycle rejection, and assigns spawn depth so parents are constructed before children.

**Order.** Raw key extraction and recursive parent depth feed the row-depth assignment.
