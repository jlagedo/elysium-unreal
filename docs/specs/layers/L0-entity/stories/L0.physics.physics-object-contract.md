# Physics object and collision interface

Layer L0 · `L0.physics.physics-object-contract` · size L · 7 rows, 1233 bytes of retail code

**Goal.** Implement object assignment and swap (`0x100a6490`, `0x100a68f0`), object enumeration and velocity reads (`0x100a6ad0`, `0x100ad1a0`), impulse writes (`0x100b2aa0`), collision-group updates (`0x100aaa40`), and `GetCollideable` (`0x10027610`).
