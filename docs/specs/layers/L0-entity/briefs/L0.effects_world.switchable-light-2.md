# Brief L0.effects_world.switchable-light-2 — Switchable light state

Layer L0 · story `L0.effects_world.switchable-light` · slice 2 of 3 · **ready**

## Goal

Use, Kill, SetPattern, and FadeToPattern share the initialized style and START_OFF state. The story: Restore the CLight startup and transition path: pitch keyvalues at `0x101303c0`, Spawn at `0x10130460`, Use at `0x10130580`, Kill at `0x101306d0`, SetPattern at `0x10130780`, and FadeToPattern at `0x10130800`.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x10130580` CLight::Use (51 B, 108 maps, open) — For styles above 31, apply ShouldToggle to the Use type and current on/off state before toggling. Port lacks: CLight registers a Toggle input but has no Use override or Use-type/ShouldToggle handling; inherited Use is empty.
- `0x101306d0` CLight::Kill (16 B, 108 maps, partial) — Turn the light off before invoking base entity Kill. Port lacks: Base Kill is carried, but the preceding TurnOff is missing. The dormancy hook checks IsHidden, so killing an unhidden light calls TurnOn instead.
- `0x10130780` CLight::InputSetPattern (85 B, 108 maps, partial) — CLight::InputSetPattern stores a string pattern, publishes the light style, and clears START_OFF. Port lacks: Pattern publication and flag clearing exist. Port adds a style >=32 guard absent here in retail and stringifies non-string inputs instead of storing an empty pattern.
- `0x10130800` CLight::InputFadeToPattern (147 B, 108 maps, partial) — CLight::InputFadeToPattern captures current and target brightness characters, stores the pattern, schedules immediate FadeThink, and clears START_OFF. Port lacks: Fade initialization and immediate scheduling exist. Port adds a style >=32 guard and stores converted non-string text; retail converts it only for the target character and stores a null pattern.
