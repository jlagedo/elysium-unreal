## Goal

Callback binding, arrival outputs, and the close sound are one completion transaction; testing them separately can miss the resynchronization defect. The story: Port the retail door arrival contract: bind the completion callback when movement starts so live `ToggleState` changes cannot redirect arrival, preserve `OnFullyClosed` when a locked door is resynchronized mid-close, and emit the one-shot `close` soundgroup at bottom arrival with no code-owned moving loop. Retail anchors: `DoorGoUp` `0x100f05e0`, `DoorGoDown` `0x100f0f50`, `DoorHitTop` `0x100f0860`, `DoorHitBottom` `0x100f11b0`, shared soundgroup event `0x100ee4e0`.
