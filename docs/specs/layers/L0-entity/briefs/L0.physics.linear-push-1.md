# Brief L0.physics.linear-push-1 — Linear pusher transaction

Layer L0 · story `L0.physics.linear-push` · slice 1 of 1 · **ready**

## Goal

Integrate local linear motion, check pushed entities in reverse order, and commit or restore with local-time rollback. The story: Advance root local origin by local velocity and interval, speculatively test a shared linear displacement, commit or roll back, and undo local time when blocked (`0x10038180`, `0x10036a20`, `0x10038400`, `0x10038710`).

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x10038180` CPhysicsPushedEntities::LinearlyMoveRootEntity (505 B, 108 maps, open) — Advance root local origin by local velocity times the interval and return the absolute-velocity displacement. Port lacks: Mover endpoint interpolation does not read the entity velocity, resolve dirty absolute velocity or return the displacement needed by pushed-entity checks.
- `0x10036a20` CPhysicsPushedEntities::SpeculativelyCheckLinearPush (177 B, 108 maps, open) — Check pushed entities in reverse order using a shared linear displacement, recording the first failed index. Port lacks: Unreal mover sweeps do not implement the retail pushed-entity list and speculative check loop.
- `0x10038400` CPhysicsPushedEntities::PerformLinearPush (618 B, 108 maps, open) — Perform an atomic linear push with hierarchy snapshots, blocker discovery, speculative checks, rollback on failure and completion on success. Port lacks: TickMove sweeps one mover body and handles its hit; it lacks the pushed-entity transaction and rollback.
- `0x10038710` CBaseEntity::PhysicsPushMove (562 B, 108 maps, open) — Advance local time, skip pushing at zero velocity, perform a linear push and undo the time increment when blocked. Port lacks: LocalTime is declared and bound, but no runtime push path increments or rolls it back. Movers use absolute trajectory deadlines.
