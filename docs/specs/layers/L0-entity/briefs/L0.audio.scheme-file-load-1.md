# Brief L0.audio.scheme-file-load-1 — SoundScheme file loading

Layer L0 · story `L0.audio.scheme-file-load` · slice 1 of 1 · **ready**

## Goal

The file loader calls the tokenizer wrapper and recursive typed parser. The story: At 0x102482b0, 0x10248510 and 0x102480f0, load or reuse a KeyValues file and populate named top-level trees with ordered leaves whose unquoted values retain integer or float types.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x102482b0` Global::FUN_102482b0 (35 B, 108 maps, partial) — Read a token into the second shared buffer, advance the input cursor, and forward optional quote-status reporting. Port lacks: Token output and cursor advancement are folded into Tokenize; quote-status reporting and full retail lexical behavior are absent.
- `0x10248510` Global::FUN_10248510 (300 B, 108 maps, partial) — Recursively parse KeyValues children and leaves, preserving strings while classifying unquoted values as integer, float or string. Port lacks: Recursive blocks and string leaves exist. Quote status is discarded, numeric type classification is absent, and leaves are collapsed into a last-value map rather than retail ordered typed nodes.
- `0x102480f0` Global::FUN_102480f0 (345 B, 108 maps, partial) — Load a KeyValues file, optionally reuse cached text, and populate named top-level sibling trees. Port lacks: File reading and nested sibling trees are carried. The parser drops quoted-versus-unquoted type information and cannot repopulate an existing named root. Empty loaded text fails instead of returning r
