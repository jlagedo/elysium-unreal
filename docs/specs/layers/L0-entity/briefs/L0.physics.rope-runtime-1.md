# Brief L0.physics.rope-runtime-1 — Rope runtime activation

Layer L0 · story `L0.physics.rope-runtime` · slice 1 of 2 · **ready**

## Goal

Create and configure rope endpoint state, then compute live length and attachment-dependent bounds.. The story: Parse rope keyvalues and endpoint handles (`0x1019f2b0`, `0x1019ddc0`, `0x1019de30`), recalculate length and bounds (`0x1019e5d0`, `0x1019e8b0`), then relink and activate through `0x1019e310` and `0x1019e430`.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x1019f540` CRopeKeyframe::Spawn (19 B, 62 maps, partial) — Run CBaseEntity::Spawn, including its field reset and zero attack-extents dispatch, then invoke rope Precache. Port lacks: Unreal construction and material loading replace the precache portion. The rope has no substrate Spawn path reproducing the base field reset and attack-extents dispatch.
- `0x1019f2b0` CRopeKeyframe::vfunc110 (454 B, 62 maps, partial) — Parse rope keyvalues: set Breakable, Collide and Barbed bits for value 1, clear the end lock for Dangling, map Type to node count, and select RopeShader material. Port lacks: The bake carries these settings, but flags accept any nonzero numeric value instead of atoi(value)==1. Unknown RopeShader values select cable/cable instead of retail's cable/chain. Ordered runtime key
- `0x1019ddc0` Global::FUN_1019ddc0 (66 B, 62 maps, open) — Assign the rope's start-entity handle, or an invalid handle for null, and always store its attachment index. Port lacks: Ropes use baked endpoint coordinates and fixed cable starts. No live start-entity handle, attachment index or equivalent setter is carried.
- `0x1019de30` Global::FUN_1019de30 (66 B, 62 maps, open) — Set the rope's end-entity handle at +0x494, or invalidate it, and store the attachment index at +0x49a. Port lacks: The cable receives a baked endpoint coordinate. No live end-entity handle or attachment-index setter exists.
- `0x1019e5d0` Global::RecalculateLength (247 B, 62 maps, partial) — Set integer rope length to the truncated distance between endpoint entity origins, or zero when the end handle is invalid. Port lacks: Baking computes the truncated initial span before deriving rest length. No live endpoint recalculation or invalid-handle zeroing of the retail length field exists.
- `0x1019e8b0` Global::FUN_1019e8b0 (617 B, 62 maps, open) — Compute local rope bounds from available attachment positions; update collision bounds when changed, or optionally relink unchanged bounds. Port lacks: Cable placement supplies visual endpoints, but no code reproduces the attachment-dependent collision box or unchanged-bounds relink branch.
