## Goal

Both are leaf buffer readers; vfunc13 is also the short-read callee of vfunc9. The story: At `0x101a1e30`, `CRestore::vfunc9` reads two unsigned shorts or skips four bytes for a null destination; `0x101a1e70` and `0x101a1ea0` read unsigned 16-bit and 32-bit words.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x101a1e70` CRestore::vfunc13 (28 B, 108 maps, open) — Read two restore-buffer bytes into a zero-initialized word and return the unsigned 16-bit value. Port lacks: No equivalent CRestore short-reader path was found in the native save implementation.
- `0x101a1ea0` CRestore::vfunc14 (27 B, 108 maps, open) — Read four restore-buffer bytes into a zero-initialized word and return it. Port lacks: Native saves use Unreal archive operators; no implementation of this retail restore-buffer primitive was found.
