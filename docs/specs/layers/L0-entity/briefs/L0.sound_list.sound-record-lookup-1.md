## Goal

The row owns the pool-presence and index-boundary contract used by both the player producer and NPC hearing. The story: `CSoundEnt::SoundPointerForIndex` (`0x101bb150`) returns `pool + 0x464 + index * 0x2c` for indices 0–63 when the global pool exists. A missing pool or invalid index returns null; an invalid index with a live pool also takes the `DevMsg` path.
