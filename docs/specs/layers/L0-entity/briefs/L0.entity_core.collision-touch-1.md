# Brief L0.entity_core.collision-touch-1 — Solid changes and untouch checks

Layer L0 · story `L0.entity_core.collision-touch` · slice 1 of 1 · **ready**

## Goal

The initializer, solid-bit comparison, touch gate, generation update, and deferred enqueue form one ordered collision contract. The story: At 0x100dc300, 0x100dc580, 0x100dc430, 0x100b11d0, and 0x100f8e20, collision state changes invalidate and refresh the required state; a non-solid non-trigger entity that touches something queues an untouch check once, using the EFlags bit and generation rules.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x100dc300` Global::FUN_100dc300 (118 B, 108 maps, open) — Initializes a collision property with its owner, zero bounds and flags, and default cached vectors. Port lacks: The port records selected solid words but has no equivalent collision-property initializer carrying the owner, complete cache state, and default vectors.
- `0x100dc580` Global::FUN_100dc580 (106 B, 108 maps, partial) — Sets collision solid flags and, on changed bits, invalidates bounds, notifies physics, and refreshes collision state. Port lacks: Callers write RetailSolidFlags and collision queries observe bit 4. The old/new comparison, 0x180 invalidation, physics notification, and 0xc refresh sequence are absent.
- `0x100dc430` Global::FUN_100dc430 (53 B, 108 maps, open) — When an entity becomes non-solid and is not a trigger, request untouch checking if it currently touches something. Port lacks: SetCheckUntouch and IsCurrentlyTouching are diagnostic stubs; the solidity-change gate and resulting untouch request are absent.
- `0x100b11d0` CBaseEntity::SetCheckUntouch (193 B, 108 maps, open) — On true, increment the untouch-check generation and set/enqueue EFlags bit 0x1000000 once; on false, clear that bit. Port lacks: The implementation ignores the boolean and only tallies. No corresponding generation increment, pending bit or untouch-check enqueue was found.
- `0x100f8e20` Global::FUN_100f8e20 (128 B, 108 maps, open) — Append an entity to the global deferred untouch-check list unless its virtual exclusion predicate succeeds. Port lacks: Its caller SetCheckUntouch is a stub; no equivalent predicate-gated deferred entity list was found.
