# Brief L0.physics.physics-object-contract-2 — Physics object and collision interface

Layer L0 · story `L0.physics.physics-object-contract` · slice 2 of 2 · **ready**

## Goal

Expose object enumeration, velocity and impulse access, collision filtering, and the embedded collideable interface.. The story: Implement object assignment and swap (`0x100a6490`, `0x100a68f0`), object enumeration and velocity reads (`0x100a6ad0`, `0x100ad1a0`), impulse writes (`0x100b2aa0`), collision-group updates (`0x100aaa40`), and `GetCollideable` (`0x10027610`).

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x100a6ad0` CBaseEntity::VPhysicsGetObjectList (163 B, 108 maps, open) — Return the entity's single physics object through the output array when an object exists and capacity is positive. Port lacks: The port always returns zero and never fills the output array.
- `0x100ad1a0` CBaseEntity::GetVelocity (292 B, 108 maps, open) — Read optional linear/angular velocity outputs from the physics object, falling back to the entity's velocity fields. Port lacks: GetVelocity is a stub and writes neither output, including the nonphysics field fallback.
- `0x100b2aa0` CBaseEntity::ApplyAbsVelocityImpulse (243 B, 108 maps, open) — Ignore a zero impulse; otherwise refresh dirty absolute velocity and assign existing absolute velocity plus the impulse. Port lacks: No equivalent additive absolute-velocity operation with the zero gate and dirty-velocity refresh was found.
- `0x100aaa40` CBaseEntity::SetCollisionGroup (151 B, 108 maps, open) — Update m_CollisionGroup only when changed and notify an existing physics object to recheck its collision filter. Port lacks: CollisionGroup exists, but its declaration explicitly states that no runtime producer writes it. No setter or physics-filter notification was found.
- `0x10027610` CBaseEntity::GetCollideable (7 B, 108 maps, open) — Return the entity's embedded m_Collision as its ICollideable interface. Port lacks: Returns null rather than a collision interface. Separate Unreal body and hull accessors do not implement this accessor.
