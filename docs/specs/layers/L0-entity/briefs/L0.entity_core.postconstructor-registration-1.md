## Goal

The constructor registration path calls SetClassname and may route invalid names into deferred removal. The story: At 0x1009f120 and 0x1009e120, SetClassname interns and assigns the class name, then PostConstructor rejects empty names or registers the entity through the retail networkable and nonnetworkable paths.

Port lacks: Maker creation folds classname replacement into ChildDef.Classname. The general setter remains a no-op, with no mutable classname member. Port lacks: Factory construction carries class identity and world-list registration, and runtime creation refuses empty classnames.
