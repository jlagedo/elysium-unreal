The story: At 0x1011b9f0, 0x1011b590, 0x10057850, 0x10057a30, and 0x10057ac0, retail builds adjacent-map counts, restores transition-mask-selected entities, and serializes or rebuilds the GLOBAL record list and global-entity table before post-restore hooks.
