## Goal

The story: At 0x1009e280, 0x1009e430, 0x101a5a80, 0x101d0310, 0x101d0630, 0x101bb4a0, 0x1009ebb0, 0x1009eca0, and 0x100acab0, retail walks ordered map pairs through virtual KeyValue, resolves inherited datamaps, parses typed values, and reads KEY or OUTPUT fields back into variants.
