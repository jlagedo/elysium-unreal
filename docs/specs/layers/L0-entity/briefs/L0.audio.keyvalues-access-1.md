# Brief L0.audio.keyvalues-access-1 — KeyValues lookup and mutation

Layer L0 · story `L0.audio.keyvalues-access` · slice 1 of 1 · **ready**

## Goal

Typed reads share lookup and conversion-writeback behavior.. The story: At 0x10248900, 0x10248bb0, 0x10248cd0 and 0x102490e0, find the first case-insensitive child through fallback links, optionally create it, read typed numeric values and write converted string values back.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x10248900` Global::FUN_10248900 (89 B, 108 maps, partial) — Find the first case-insensitive child key, search a fallback chain if absent, and optionally create a missing child. Port lacks: Case-insensitive leaf and block lookup exist separately. Missing fallback-chain search, optional creation, and unified first-match lookup across ordered key nodes.
- `0x102490e0` Global::FUN_102490e0 (94 B, 108 maps, partial) — Find or create a KeyValues entry, replace its owned string value, and reset its type to string. Port lacks: Parse-time string insertion and replacement exist. Missing the runtime find-or-create setter, fallback-chain lookup, and typed-node reset.
- `0x10248cd0` Global::FUN_10248cd0 (139 B, 108 maps, partial) — Read a KeyValues string with a fallback, converting numeric node values to strings and writing the conversion back. Port lacks: String lookup and absent-key fallback are carried. All leaves remain strings, so typed numeric formatting and conversion writeback are missing.
- `0x10248bb0` Global::FUN_10248bb0 (74 B, 108 maps, partial) — Read a KeyValues integer with a fallback, parsing string nodes and truncating float nodes. Port lacks: Lookup, fallback and string atoi behavior are carried. Typed float conversion is absent; atoi on retained text does not reproduce every float-to-integer result.
