# Brief L0.audio.sound-script-resolve-1 — Sound script resolution

Layer L0 · story `L0.audio.sound-script-resolve` · slice 1 of 2 · **ready**

## Goal

The resolver directly composes the interval and wave-selection helpers.. The story: At 0x1012f700, 0x101b3240 and 0x101b33f0, evaluate fixed or random parameter intervals, prefer category-matching waves with all-wave fallback, and validate the resolved sample.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x1012f700` Global::FUN_1012f700 (53 B, 104 maps, open) — Evaluate a sound parameter interval, returning its fixed value when the range is zero and sampling otherwise. Port lacks: No sound-script interval evaluator or corresponding parameter records were found. Random draws for unrelated wave pools do not carry this helper.
- `0x101b3240` Global::FUN_101b3240 (324 B, 104 maps, open) — Randomly select a wave index matching the requested category, falling back to all waves and returning -1 for an empty list. Port lacks: The script wave list and its category metadata are absent. Other random wave selectors do not implement the matching-category preference and fallback.
- `0x101b33f0` Global::FUN_101b33f0 (607 B, 104 maps, open) — Resolve a sound script into playback parameters, sample parameter intervals, select a wave and validate the resulting sample. Port lacks: The runtime explicitly has no sound-script table or resolver. Direct-wave playback and folder-based substitutes do not reproduce this parameter-resolution behavior.
