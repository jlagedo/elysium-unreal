# Brief L0.audio.keyvalues-tree-1 — KeyValues file tree parsing

Layer L0 · story `L0.audio.keyvalues-tree` · slice 1 of 1 · **ready**

## Goal

The file reader depends on the token wrapper and recursive block parser. The story: At 0x101f2f30, 0x101f2360 and 0x101f2180, read a whole file into named roots, recursively parse blocks and classify unquoted numeric leaves while preserving quote provenance and root reuse.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x101f2f30` Global::FUN_101f2f30 (35 B, 108 maps, partial) — Read a token into the shared buffer, advance the input cursor, and optionally report whether it was quoted. Port lacks: Cursor advancement and token output are folded into Tokenize; quoted-token reporting and the full retail lexical rules are missing.
- `0x101f2360` Global::FUN_101f2360 (262 B, 108 maps, partial) — Recursively parse VKeyValues blocks, intern names/values and classify unquoted leaves as integers or floats. Port lacks: Tokenization, brace recursion and leaf storage are carried. Quote provenance and retail numeric type inference are discarded; all leaves remain strings.
- `0x101f2180` Global::FUN_101f2180 (384 B, 108 maps, partial) — Read a whole file and construct or reuse named root KeyValues nodes, requiring an opening brace before recursively parsing each block. Port lacks: File loading and nested parsing exist. Retail root-node reuse, malformed-opening-brace recovery, and typed leaf representation are absent.
