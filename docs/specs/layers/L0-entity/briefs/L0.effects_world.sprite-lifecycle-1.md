# Brief L0.effects_world.sprite-lifecycle-1 — Sprite lifecycle and animation state

Layer L0 · story `L0.effects_world.sprite-lifecycle` · slice 1 of 1 · **ready**

## Goal

Spawn, Use, and the I/O wrappers converge on one TurnOn/TurnOff animation state. The story: Restore `CSprite::Spawn` at `0x1042e550`, TurnOn at `0x1042ef70`, Use at `0x1042f030`, and Hide/Show/Toggle inputs at `0x1042f080`, `0x1042f0a0`, and `0x1042f0c0`, including effects-word comparison, frame reset, and think timing.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x1042ef70` Global::FUN_1042ef70 (129 B, 97 maps, partial) — Turn a sprite on, conditionally schedule animation think and timestamps, reset its frame, and force transmission. Port lacks: Visibility restoration is carried. Conditional animation scheduling, timestamps, and frame reset are absent. ForceTransmit belongs to replaced networking.
- `0x1042e550` CSprite::Spawn (593 B, 97 maps, partial) — CSprite::Spawn initializes collision, model and animation frames, chooses initial visibility, adjusts angles, clamps scale, and initializes brightness. Port lacks: Initial visibility and noncollision are implemented; material, size, and color are baked. Retail frame/max-frame initialization, animation scheduling, and angle adjustment are absent from the runtime 
- `0x1042f030` CSprite::Use (63 B, 97 maps, open) — CSprite::Use applies ShouldToggle to the requested use type and current effects state, then turns the sprite off or on. Port lacks: The sprite leaf inherits the empty Use handler. Visibility inputs exist, but no Use override or USE_TYPE/ShouldToggle dispatch reproduces this function.
- `0x1042f080` CSprite::InputHideSprite (8 B, 97 maps, partial) — CSprite::InputHideSprite delegates to TurnOff, which sets NODRAW and clears next-think time. Port lacks: Hiding reaches the baked actor. TurnOff's retail next-think reset is absent.
- `0x1042f0a0` CSprite::InputShowSprite (8 B, 97 maps, partial) — CSprite::InputShowSprite delegates to TurnOn, clearing NODRAW, resetting the frame, and conditionally scheduling animation. Port lacks: Showing reaches the baked actor. Frame reset, framerate/max-frame or spawnflag-2 animation scheduling, and animation clock initialization are absent; ForceTransmit is networking.
- `0x1042f0c0` CSprite::InputToggleSprite (25 B, 97 maps, partial) — CSprite::InputToggleSprite selects TurnOff or TurnOn using the exact comparison m_fEffects != 0x40. Port lacks: Visibility toggles through bOn. Port lacks retail's exact effects-word comparison and the delegated frame reset, animation scheduling, and next-think clearing.
