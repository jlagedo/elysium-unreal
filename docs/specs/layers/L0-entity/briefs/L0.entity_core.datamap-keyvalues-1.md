# Brief L0.entity_core.datamap-keyvalues-1 — Datamap keyvalue parsing and reading

Layer L0 · story `L0.entity_core.datamap-keyvalues` · slice 1 of 2 · **ready**

## Goal

Typed conversions and the descriptor must be available before callers dispatch map keys.. The story: At 0x1009e280, 0x1009e430, 0x101a5a80, 0x101d0310, 0x101d0630, 0x101bb4a0, 0x1009ebb0, 0x1009eca0, and 0x100acab0, retail walks ordered map pairs through virtual KeyValue, resolves inherited datamaps, parses typed values, and reads KEY or OUTPUT fields back into variants.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x101d0310` Global::FUN_101d0310 (154 B, 108 maps, partial) — Parse up to a requested number of whitespace-delimited floats from a 128-byte string copy and zero-fill remaining elements. Port lacks: ElysiumParseVec3 covers complete three-component inputs, but returns an entirely zero vector for fewer components. Retail preserves parsed components and zero-fills the remainder; generic count and tr
- `0x101d0630` Global::FUN_101d0630 (55 B, 108 maps, open) — Parses four space-separated integers and packs their low bytes into an RGBA color. Port lacks: The base rendercolor arm skips its write and color32 has no field marshaller. Class-specific linear-color parsing does not reproduce this four-byte conversion.
- `0x101bb4a0` CAISound::vfunc82 (6 B, 108 maps, open) — Return the static CAISound datamap descriptor. Port lacks: GetDataDescMap returns null; no CAISound-specific descriptor or equivalent class registration was found.
- `0x101a5a80` Global::FUN_101a5a80 (456 B, 108 maps, partial) — Recursively finds a case-insensitive KEY datamap field and converts text into its scalar, string, vector, color, or custom type. Port lacks: Base-chain lookup and common scalar/string/vector conversions exist. The dispatch does not enforce retail's KEY flag, lacks embedded-datamap recursion and full color/custom parsing, and vector parsing
