## 0x102f7130 Global::FUN_102f7130 (319 B)

- **Signature:** `void __cdecl (float *out, float *p2, float *p3, float *eye)`. Straight-line, no branches. Writes `out[0..2]` only. Other stores hit caller-argument slots (`[ESP+0x28]`, `[ESP+0x2c]`, i.e. the callee's own `p2`/`p3` argument slots) and the local frame.
- **Callers:** `0x102f72c0` only (through thunk `0x100121d9`), as `(out = &P, p2 = src, p3 = dst, eye)`; pushed in the order eye, dst, src, out (asm `102f742d`–`102f743c`).
- **Arms (retail order):**
  1. `d = p3 − p2`; `v = eye − p2`.
  2. `|v|² = v·v`, `|d|² = d·d`, each stored as a float; `|v| = sqrt(|v|²)` stored as a float; `|d| = sqrt(|d|²)`.
  3. `DOT = v·d` (stored as a float). Denominator `den = float(|d| · float|v|)`. `s = (DOT / den) · |v|₂`, where `|v|₂` is a **second** `sqrt(|v|²)` left unrounded in ST0, stored as a float. Mathematically `s = v·d / |d|`.
  4. `d' = VectorNormalize(copy of d)` = `d · 1/(FLT_EPS + |d|)`. The returned ST0 (`|d|`) is popped and discarded (asm `0x102f7217`).
  5. `out = p2 + d'·s`; stores x, y, z to `out[0..2]`.
- **Returns:** void.
- **Degenerate, retail-exact:** `|d| = 0` → `DOT/0` = 0/0 = NaN. `eye == p2` → `|v| = 0` → NaN. Either way `out = NaN` (`d'·NaN` is NaN even for a zero `d'` component).
- **Port today:** `Source/ElysiumUE/Private/Player/ElysiumCameraSolve.cpp:358`–`377`, `ElysiumCam::ClosestPointParameterOnLine` (`t = (P−A)·(B−A) / |B−A|²`) and `ClosestPointOnLine` (`A + (B−A)·t`). Header `Public/ElysiumCameraSolve.h:74`–`77`. These port the **camera's** closest-point kernel `FUN_1013c940` / `FUN_1013ca00` (which has the `1e−5` guard in retail), not `0x102f7130`; the math is the same infinite-line projection. Divergences from `0x102f7130`:
  - Guard at `:362`: `|B−A|² < ClosestPointLengthEpsilon` (`:349`, 1e−5·U²) → `t = 0` → out = A. `0x102f7130` has no guard and gives NaN. For a zero-length link the port's point is finite; a picker built on it would accept that link (segment tests pass with S = 0). Retail rejects it at the score gate. This is a silent behaviour change and needs a named-modernization decision, or a separate projection that keeps the NaN.
  - Normalisation: retail multiplies by `d' = d/(ε+|d|)`. The port is exact. The relative difference is `|d|/(ε+|d|)` ≈ 1 − 1.2e−7/|d|. Not bit-exact.
  - Precision: the port computes in double (`FVector`) and casts. Retail rounds `|v|²`, `|d|²`, `|v|`, the product, `DOT` and `s` to float between x87 steps.
  - Only caller: `AutoPositionFromTarget` at `:401` (camera). No link-selection caller.
