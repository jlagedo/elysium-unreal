# Walk L0-r034

Scope: the four brief addresses, plus `0x102f7130` (walked as a callee because `0x102f72c0` depends on it). Read-only. Decompile and asm both read; the asm wins where they differ (it differs here in the wrapper argument count and return, the `GetPosition` return, the debug sink, and the normaliser calls). Port citations are `file:line` against HEAD `d4d8bf10`.

## Brief corrections

- `0x101727a0` takes **two** stack arguments `(ent, nodeFilter)`. The decompile's 4th picker argument `(int)param_1` is really `[entry+8]` in the asm (`MOV ECX,[ESP+0x30]` at `0x101727d8`, pushed at `0x101727e3`; the sret call at `0x101727c9` is callee-cleaned, so `[ESP+0x30]` is the wrapper's second argument, not `ent`). Every call site pushes `nodeFilter` then `ent` (see Callers).
- Both wrappers **return the pick**. Nothing touches `EAX` after the picker call (`0x101727fc`..`0x10172803`, `0x10172887`..`0x1017288e`); the decompile's `void` is wrong, and every caller reads the result.
- Both wrappers **have callers**: through thunks `0x1000392c` and `0x10003c24` (a direct-reference search on the wrappers themselves finds nothing, which is why a first pass saw none). They are the in-game node and link editor (`wc_*` commands), two `ai_show_*` debug commands and a per-frame overlay (Callers).
- `0x10146150` is not an L4 hook. It is `VectorLength` (`sqrt(x²+y²+z²)`, sum stored to float, then `FSQRT` through `0x101371d0`, result on x87). L0 math; build it now.
- `0x1000d99a` is a 5-byte `JMP` to `CAI_Node::GetPosition` at `0x102fb0d0` (619 B). The hook address is `0x102fb0d0`. It is `__thiscall` with `RET 8` and it **returns `out` in EAX** on every path (`mov eax,[esp+0x38]` at `0x102fb2dd`/`0x102fb2f9`); `0x102f6d80` reads the result through EAX. The decompile's `void` is wrong. The port already carries this function (see `0x102f6d80` Port today), so it is not an unbuilt hook.
- `0x102dda40` (CAI_Link other-end accessor, `thiscall(link, int node)`, `RET 4`) is called by `0x102f72c0` and is missing from the hook list (`hooks.tsv` has no row for it). It has 22 other callers (the link walkers). It reads link words written by the L4 navigation builder.
- "0.9 alignment threshold" is a true cosine: the candidate vector is normalised before the dot. Confirmed for both pickers (`dir` is used raw, so a unit `dir` is a precondition; `AngleVectors` supplies one).
- The port's "equivalent" projection, `ElysiumCam::ClosestPointOnLine` (`Private/Player/ElysiumCameraSolve.cpp:375`), is, per its own header (`Public/ElysiumCameraSolve.h:62`), retail `FUN_1013c940`, not `0x102f7130`. It computes the same infinite-line closest point (to float precision for `|d|` above a few units) but carries a degenerate-length guard (`:362`, `1e-5` in squared source units) that `0x102f7130` lacks.
- The debug-line sink `0x10146570` is a **seven-argument** wrapper that lifts **both** endpoints by 0.1 in Z. The one-argument decompile hides it (Open question 5).

  8. `s = |w| · tan θ` (`FPTAN` on the float θ, `|w|` from the copy of `w`). `ld = Pj − Pi`; `Lℓ = |ld|` (the normaliser's return, stored to float); `û = ld · (1 / (FLT_EPSILON + Lℓ))`; `t = û · s` (VectorScale `0x100a19c0`); `C = Q + t`. Since `θ ∈ [0, 1.57]`, `tan θ ≥ 0`, so C always lies on the +ld side of Q.
  9. Segment bounds: continue only if `|C − Pi| ≤ Lℓ` (`0x102f7615`) and `|C − Pj| ≤ Lℓ` (`0x102f768d`), each `JZ` skip on "greater". For C on the line this is `C ∈ [Pi, Pj]`. NaN passes both.
  10. Score: `cC = normalise(C − origin) · dir` (normaliser at `0x102f76ef`; the earlier one at `0x102f7546` normalises `ld`). Continue only if `cC > best` (`best` starts at `thr`; `FCOMP [L+0x3c]`, `AND 0x4100`, `JNZ` skip; strict, and NaN skips here).
  11. Visibility: `Ray_t::Init(origin, C)` (`0x1004f7a0` via thunk `0x10015929`, call `0x102f7738`); filter `(0, 0)`; `TraceRay(ray, 0x02804091, filter, trace at L+0xf0)` (`0x102f7772`).
  12. Debug gate (`0x1005f190`, call `0x102f777a`) → line from `trace.startpos` to `trace.endpos` (`0x102f77a3`).
  13. `trace.fraction == 1.0` (`0x102f77b2`) → `best = cC`, `bestLink = L` (`0x102f77bf`).
