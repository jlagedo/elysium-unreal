## Record notes

`l0_blood_effects` (arena). The file `Arena/scenarios/world/l0_blood_effects.json` does not exist yet (checked at HEAD and in the tree). The arena README documents no `trace_attack` action yet (the brief lists it as NEW).

- **Colour is not a packet field.** The colour is the victim's slot-145 `BloodColor()` (`CBaseCombatCharacter` 0x1014fa10 reads `m_bloodColor` at `+0x1570`; `CBaseEntity` 0x10026d90 answers -1). The record must set the victim's `m_bloodColor` and drive the path through `trace_attack`. The brief's "packet colour" wording is wrong.
- **Zero amount.** Through `CAI_BaseNPC::TraceAttack` it is not reachable: `SpawnBlood` sits behind `1.0 <= damage` (retail double 0x10449280 = 1.0; port `ElysiumNpcBaseDamage.cpp:175`), so `__ftol` gives >= 1. A record that stays on the NPC route cannot test amount 0.
