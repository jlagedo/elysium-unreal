First pass by a Haiku reader, then re-read against the corpus by a confirming reader (see `## Confirmation`).

## Shared node layout (from asm; class and field names unresolved)

`vtmb_fields KeyValues` and `vtmb_closure KeyValues` return no structure, so the labels below are descriptive. The node is 0x1C bytes (`operator_new(0x1c)` at 0x102481bb and in `FUN_10248870`). Memory comes from `operator_new` (0x104312d5 -> `__nh_malloc`), which does not zero it.

| offset | role | evidence |
|---|---|---|
| +0x00 | name (char*), an `operator_new` copy of the token | name setter `FUN_10247cf0`; getter `FUN_102480b0` (fastcall, `return *this`) |
| +0x04 | value text (char*), an `operator_new` copy; NULL on blocks and roots (the setter zeroes it) | copied by 0x10248510 arm 6 and by `FUN_102490e0`; read by 0x10248bb0/0x10248cd0 |

Retail bug worth knowing: `FUN_10249160` / `FUN_102491a0` / `FUN_102491e0` store the numeric into the found child (`[EAX+8]`) but store the type into `this` (`MOV [ESI+0xc],n` with `ESI = this`, asm 0x1024917a / 0x102491fa), not into the child. Not one of the seven; recorded because it feeds the type the typed readers dispatch on.

Global side state (resolved by the confirming reader): `DAT_10753f68` is a `char[0x40]`, the "current FindNext name": `FUN_10248af0(this, name)` copies `name` into it and returns the first child whose name matches (`strcmpi`); `FUN_10248b60(node)` continues from `node->+0x10` with the stored name; `FUN_10248a70` / `FUN_10248ab0` push / pop it on a 0x20-deep stack of 0x40-byte slots at `DAT_10753fa8` (depth `DAT_10856fac`). The name setter (`FUN_10247cf0`, byte write at 0x10247d36) and the destroyer `FUN_10247da0` clear its first byte, so creating, renaming or destroying any node cancels an in-progress FindNext loop. Not used by the seven addresses beyond that clear.

## 0x102482b0 FUN_102482b0 (35 B)

- Signature: `char* __cdecl (char** cursor, char* quoted_out)`. Asm 0x102482b0-0x102482d2: pushes `quoted_out`, `0x10754fa8`, `*cursor`; calls thunk `0x10004273` -> `FUN_10247280`; stores the result to `*cursor`; returns `0x10754fa8`.
- Callers (DIRECT, 3): 0x102480f0, 0x10248430, 0x10248510.
- Arms: none. Returns the shared buffer on every path, including EOF (cursor becomes NULL, buffer is `""`).
- Writes: `*cursor` (the lexer's return); the token buffer (by the lexer); `*quoted_out` (one byte, by the lexer).
- Callee: `FUN_10247280` (cdecl `char* (cursor, out, quoted*)`), the KeyValues lexer (`keyvalues-lexer` story). Its arms, as needed for this wrapper's observable (asm 0x10247280-0x1024738a read; `MOVSX` on every byte):
  1. `quoted != NULL` -> `*quoted = 0` (byte).
  2. `cursor == NULL` -> return NULL; the buffer is untouched (so a read after EOF returns the stale `""`).
  3. `FUN_102473e0()` one-time table init (flag `DAT_10753640`): `FUN_1023eff0(table, literal)` zeroes 256 bytes then sets `table[(signed char)c] = 1` for each literal character.
  4. table = `DAT_10753641 != 0 ? DAT_10753440 : DAT_10753540`. `DAT_10753641` is never written (3 lexer thunks and the lexer read it; initial 0), so the table is `DAT_10753540`, characters `{ } ( ) ' :`.
  5. `out[0] = 0`.
  6. skip while `(signed char)c <= 0x20`; NUL -> return NULL with `out == ""`. Bytes >= 0x80 are negative and are skipped as whitespace.
  7. `//` -> skip to `\n`/NUL, restart. `/*` -> skip to `*/` (or NUL), restart. A lone `/` is an ordinary character.
  8. `"` -> `*quoted = 1`; copy to the closing quote; `\"` -> `"`; any other backslash is copied literally; cursor after the closing quote. Unterminated: the loop stops at NUL and the cursor becomes NUL+1 (asm 0x10247330-0x10247380: retail then reads past the buffer).
  9. `table[c] != 0` -> one-character token; cursor after it.
  10. bare run: copy until a table character, a byte <= 0x20, or a byte >= 0x80 (signed compare); cursor at that character. `//` inside a bare run is not a comment.
- Port today: no wrapper. `ElysiumKeyValues.h:67-103` `Tokenize` returns an `FString` list over the whole text. Divergences:
  - no cursor and no quote-status output (`quoted` is needed by 0x10248510 arm 7/8);
  - no `/* */` comments (retail arm 7);
  - only `{` and `}` are single-character tokens (line 80); retail also splits on `(`, `)`, `'`, `:` (arm 9/10), so a bare `a:b` is three tokens in retail. A scan of the deployed `Content/ElysiumCorpus` with a re-implementation of this lexer found no such bare token and no `/*` in the 174 `sound/schemes` files; five `vdata` files carry them (`system/credits.txt`, `credits - hunter.txt`, `credits - vampire.txt`, `experience_table.txt`, `masquerade.txt`);
  - whitespace is `FChar::IsWhitespace` (line 74); retail is `<= 0x20` signed, so bytes >= 0x80 are whitespace between tokens and end a bare run;
  - EOF is list end, not a NULL cursor;
  - unterminated quote: port tolerates (line 91); retail overruns (no retail-observable value to copy).

## 0x10248510 FUN_10248510 (300 B)

- Signature: `void __thiscall (node* this /*ECX*/, char** cursor, FileSys* fs)`, RET 8. The third argument is the file-system pointer that `0x102480f0` received (`param_2`); it is forwarded to the recursive call only (asm 0x1024857f-0x1024858b) and never read.
- Callers: DIRECT via thunk `0x1000a321`: 0x102480f0, 0x10248430, and itself (recursion).
- Arms, in retail order (loop head at 0x1024851b; `local_c = this` is the current block):
  1. `key = read(cursor, NULL)`; `key == NULL` or `*key == 0` -> return. An empty quoted `""` in key position also returns, ending the block early.
  2. `key == "}"` (2-byte compare against `7d 00` at `0x10547b64`) -> return. The quote flag is not read for the key, so a quoted `"}"` also closes the block.
  3. `child = CreateChild(this, key)` (thunk `0x10004eee` -> `FUN_10248870`). Created before the value is read.
  4. `val = read(cursor, &quoted)` (quote flag in the byte at `[ESP+0x13]`).
  5. `val == "{"` (2-byte compare against `7b 00` at `0x10547b78`) -> `FUN_10248510(child, cursor, fs)` (thunk `0x1000a321`), then back to arm 1. The brace test ignores the quote flag: `"{"` opens a block. A `}` in value position is not a block end: it falls to arm 6 and is stored as a string value.
  6. Value: `free(child->+0x04)` if non-NULL (dead for a fresh child); copy `val` (length+1, `operator_new`) -> `child->+0x04`.
  7. `quoted != 0` -> `child->+0x0C = 0`. No numeric parse.
  8. Unquoted: `ei = strtol(val, &end_i, 10)` (0x104319a8 -> `_strtoxl`, VC6 SP5 libc); `ef = strtod(val, &end_f)` (0x1043190e, double in st0). Comparisons are unsigned pointer compares:
     - `end_f > end_i` (`JBE` at 0x1024860c not taken) -> `child->+0x08 = (float)ef` (`FSTP float`), `+0x0C = 2`.
     - else `end_i > val` (`JBE` at 0x1024861f not taken) -> `child->+0x08 = ei` (int32), `+0x0C = 1`.
     - else -> `+0x0C = 0`.
  9. Loop to arm 1.
  - CRT facts that decide the types (both copies read in vampire.dll): `_strtoxl` with explicit base 10 never reads a `0x` prefix, skips leading whitespace, accepts one sign, and saturates on overflow (positive `0x7fffffff`, negative `0x80000000`, errno 0x22) with `end_i` just past the digits; with no digits it sets `end_i = val`. `_strtod` -> `__fltin` -> `___strgtold12` is a decimal state machine: sign, digits, locale decimal point (`DAT_106b0d60`), exponent letter `e E d D`; no hex, no `inf`/`nan`; with no digits `end_f = val`.
  - Resulting classes: `50`, `+5`, `-3` -> int; `0.5`, `.5`, `5.`, `1.5e3`, `1d3` -> float (1500, 1000); `3abc` -> int 3; `abc`, `-`, `+` -> string (type 0); `0x10` -> int 0 (strtol and strtod both stop after the `0`, so `end_f == end_i`); `10000000000` -> int 2147483647 (strtol saturates, `end_f == end_i`); `1e10` -> float 1e10 (exact in float32: 9765625 * 2^10). These are read from the CRT bodies, not probed.
- Writes: `child->+0x04/+0x08/+0x0C`; heap (`free`, `operator_new`); CreateChild appends to `this`'s list (walks `+0x10` to the tail, sets the tail's `+0x10`, O(n)); the name setter inside CreateChild clears the first byte of the FindNext buffer `DAT_10753f68`.
- Callees: `FUN_102482b0` (above); `FUN_10248870` (CreateChild); `FUN_10248510`; `FUN_10430964` (11-byte wrapper, the `free` used for node memory); `operator_new` (0x104312d5); `_strtol` (0x104319a8); `_strtod` (0x1043190e). The decompile of the `strtol`/`strtod` call is garbled; asm 0x102485e5-0x10248626 was used.
- Returns: void; cursor advanced in place.
- Port today: `ElysiumKeyValues.h:105-127` `ParseBlock`. `{` -> `Kids` (line 117); values -> `Values.Add` (line 121, last wins) and `Pairs`. Divergences:
  - no type classification (arm 7/8 missing entirely);
  - an empty key token does not end the block (arm 1);
  - a trailing key at EOF: retail creates a child with `""`, type 0 (arm 4 reads `""`, arm 8 gives string); the port drops it;
  - leaves are not nodes: repeated leaf keys are kept in `Pairs`, `Values` keeps the last, while retail keeps every child in order;
  - the key is lower-cased at parse (line 112); retail keeps case and compares with `strcmpi`;
  - brace tests (`T == "}"` line 111, `Toks[Pos] == "{"` line 114) match retail's text compares; the port also treats a `}` in value position as a value (line 121), like retail.

  4. `n = fs->Size(h)` (vtable +0x18); `buf = malloc(n+1)` (0x104320f7); `fs->Read(buf, n, h)` (vtable +0x08, arguments `buf, n, h`); `fs->Close(h)` (vtable +0x04); `buf[n] = 0`. The epilogue frees it with `_free` (0x10431641, at 0x1024822c-0x10248235), so the file text is freed at return; a hook text is never freed.
  5. `cursor = buf`.
  6. Parse loop (the cursor advances in place; `this_cur` starts as `this`, `prev` as NULL):
     - `tok = read(&cursor, NULL)`; `cursor == NULL` -> break. An empty or all-comment text breaks here with no roots.
     - If `this_cur == NULL` (every root after the first, and the first when `this` was NULL): `operator_new(0x1c)`, ctor `0x10247ba0(node, tok)` (thunk `0x1000e363`: `*node = 0; name-setter(node, tok)`); link it after the previous root (`0x10012b9d` -> `FUN_10248a50` sets `prev->+0x10`).

### `l0_scheme_file_load` (map:sp_tutorial_1, time 0)

Retail path for the witness: `CSoundScheme::Precache` (0x1022a4b0) -> `FUN_1022a930` -> `0x102480f0(node "SoundScheme", "sound/Schemes/SP_Tutorial_City.txt", DAT_1070b238, 0, 1)`. Retail-observable probes. Tags follow the `retail_site` text form in `harness.md`; emit each at the port function that implements the address.

- Empty text (or only whitespace and comments): `result=1 roots=0`. If the caller's node is non-NULL (as in `CSoundscapeSystem::Init` and `FUN_1022a930`), its name stays unchanged; with any token in the file the first root renames the caller's node to that token.
