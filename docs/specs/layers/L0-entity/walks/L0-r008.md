## 0x1012f700 FUN_1012f700 (53 B)

- **Signature:** `float __cdecl sample(float* p)`. `p[0]` = base, `p[1]` = span. Result on x87 ST0. Caller pops.
- **Callers:** `101b33f0` at three sites (via `thunk_FUN_1012f700` = `100153fc`, whose only direct caller is `101b33f0`): `101b3449` (volume), `101b3455` (pitch), `101b34e4` (soundlevel). `vtmb_callers` on the function reports 0 direct (thunk indirection); `graph.tsv:1559` confirms.
- **Arms (retail order):**
  1. `p[1] == 0.0f` -> return `p[0]`. Asm: `FLD [EDX+4]`, `FCOMP [0x104454c4]` (`0x1012f707`), `MOV EAX,[EDX]` / `MOV [ESP+4],EAX` (`0x1012f70f`, the base overwrites the argument slot), `FNSTSW`, `TEST AH,0x44`, `JNP 0x1012f730` (`0x1012f718`). Equal (C3 set) leaves one bit in the mask, PF = 0, jump taken; greater, less (mask 0, PF = 1) and unordered (mask `0x44`, PF = 1) fall through. `-0.0` equals `0.0`. Return path `0x1012f730`: `FLD [ESP+4]`.
  2. Otherwise (span != 0, negative, or NaN) -> `r = VEngineRandom001.slot1(0.0f, p[1])`: `PUSH [p+4]` (`0x1012f723`), `PUSH 0` (`0x1012f724`), `ECX = DAT_1070b244`, `CALL [vtbl+4]` (`0x1012f728`); the callee pops the 8 bytes. Return `r + p[0]` (`FADD [ESP+4]` at `0x1012f72b`). The span dword is pushed raw, so a NaN payload reaches RandomFloat unchanged.
- **Draws:** one `GenerateRandomNumber` call iff span != 0.0 (RandomFloat never rejects). None otherwise.
- **Writes:** none in the game. Only the global random stream state (`CUniformRandomStream` seed/shuffle table).
- **Callees:** `VEngineRandom001` slot 1 (body recovered, see Shared facts).
- **Returns:** `base` (span = 0), else `base + span * x` with `x` in `[0, 0.99999988079]`. Span > 0: `[base, base + span)`. **Span < 0 is not rejected**: the formula is linear, so the sample lies in `(base + span, base]`. The sum is formed at x87 precision and rounded to float only when a caller stores it (`FSTP` in `101b33f0` for volume) or truncated by `__ftol` (pitch, soundlevel). UNRECOVERED: the runtime x87 precision control (D3D may set 24 bit), hence whether `trunc(base + span * x)` is computed on a float32 or an extended sum.
- **Port today:** no port line cites `0x1012f700` (`research where`: none in `Source/`; `git grep` at HEAD: none). `docs/specs/layers/audit.tsv:123` points at `Source/ElysiumUE/Private/Audio/ElysiumWaterAudio.h:32`, which is a comment about the missing script table, not an evaluator. The port has no base+span interval evaluator and no stream shared with the retail draw order.

## 0x101b3240 FUN_101b3240 (324 B)

- **Signature:** `int __stdcall pick(int* list, int category)`, `RET 8`. Returns an index in EAX.
  - `list[0]` = entry array base; `list[3]` (`list+0x0C`) = count (`CUtlVector` layout: ptr, allocCount, growSize, size).
  - Entry is 8 bytes: ushort symbol at `+0`, dword category at `+4`. `+2` is not read here.
- **Callers:** `101b33f0` at `101b349a` only (via `thunk_FUN_101b3240` = `1000bfff`, whose only direct caller is `101b33f0`). Called with `category = 0` and `list = rec+0x20`. `vtmb_callers` on the function reports 0 direct.
- **Arms (retail order):**
  1. `count < 1` -> return `-1` (`0xFFFFFFFF`). No RNG draw. (`0x101b324f`-`0x101b325e`)
  2. Scan `i = 0 .. count-1`: if `entry[i].category == category` (`CMP [EDX+EDI*8+4],EAX` at `0x101b3289`), append `i` to a stack `CUtlVector<int>` (`thunk_10071ae0` = `1000794b`: grow by 1, capacity 8 then doubling, `Plat_Alloc`/`Plat_Realloc`; `thunk_10071ba0` = `10002ec8`: `ShiftElementsRight(oldSize, 1)`, a no-op `memmove` at the end). `m` = number of matches.
  3. `m >= 1` -> `k = RandomInt(0, m-1)` (`0x101b32d0`, slot 2) -> return `matches[k]`. **`m == 1` draws nothing** (RandomInt(0, 0) returns 0 without a generator call).
  4. `m == 0` -> return `RandomInt(0, count-1)` (call at `0x101b3330`, slot 2). Every entry is a candidate. **`count == 1` draws nothing.**
  - The temp vector is freed with `Plat_Free` (`[0x109f3624]`) only when memory was allocated and the grow size is not -1, which is the matched path (`0x101b32f4`). The `m == 0` path never allocated, so the `Plat_Free` at `0x101b3353` is dead. No observable effect.
- **Draws:** `count < 1` or a candidate set of exactly one: none. Otherwise at least one `GenerateRandomNumber` (RandomInt rejection loop; the retry probability is `(0x80000000 % n) / 2^31`, tiny for small `n`). The first draft said "exactly one when `count >= 1`"; that was wrong for a single candidate.
- **Writes:** temp heap only. No globals, no entity I/O, no sound emit.
- **Callees:** `thunk_10071ae0` (`1000794b`, ledger L0), `thunk_10071ba0` (`10002ec8`, ledger L1), `Plat_Free` (TIER0), `VEngineRandom001` slot 2 (body recovered).
- **Returns:** `-1` | matched index | any index in `[0, count-1]`.
- **Category values in retail data** (recovered here from the producer `101b3830` / `101b3770`, called by the script parser `101b3bb0` for every `wave` key and every child of `rndwave`): a wave name without `$gender` is added with category **0**; a name containing `$gender` is expanded into two entries, `<pre>male<post>` with category **1** and `<pre>female<post>` with category **2**. `101b33f0` always asks for category 0, so a script whose waves all contain `$gender` takes arm 4 and picks uniformly among the male and female entries.
- **Port today:** no port line cites `0x101b3240`. `audit.tsv:125` points at `Source/ElysiumUE/Private/Audio/ElysiumSurfaceSoundTable.cpp:14` (`FirstScript`, which carries a script name verbatim). No category-matched wave pool exists. `Source/ElysiumUE/Private/Substrate/ElysiumFootsteps.cpp:73-76` picks `Pool[Stream.RandRange(0, Pool.Num() - 1)]` from the flattened bake and its comment says retail "leaves the pick to the sound engine"; for a script name that reaches `101b0dc0` / `101b1120` the pick is made here, server-side, by `101b3240` (not re-walked for the footstep callers, so treat as a lead).
