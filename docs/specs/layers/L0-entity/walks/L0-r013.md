# Walk L0-r013

Read-only walk of the 10 retail addresses in the three briefs (sprite x6, illusionary x1, blood x2), plus the callees that decide their branches. First pass by a Haiku reader; every function section was then re-read and corrected by a confirming reader against the corpus (`vtmb_code`, `vtmb_asm`, `vtmb_fields`, `vtmb_vtable`, `vtmb_callers`, `vtmb_globals`, `vtmb_readers`, `uv run elysium research where`, `pe.py`) and the port files at HEAD (`git status` shows no source file modified, so tree and HEAD agree). See `## Confirmation` at the end for the per-function verdicts.

Constants: `pe.py const` works (system python); every `.rdata` constant below is decoded from the bytes. Addresses past `.data` raw end (`0x106b9000`, vampire.dll) are BSS: `pe.py` reads them as zero, which is not their runtime value; each BSS global used here is classified by its corpus writers.

## 0x1042ef70 FUN_1042ef70 — sprite TurnOn (129 B)

- **Signature.** `void __fastcall(this=ECX)`, **no stack argument.** The decompile's `in_stack_00000004` is a phantom: TurnOn ends in `JMP 0x1000e859` (asm `1042efec`), and the target `CBaseEntity::ForceTransmit` (0x1009d1e0) is a plain `RET` (asm `1009d265`, no immediate), so nothing is forwarded.
- **Callers.** Through thunk 0x1000c3ce (8 direct callers): `CSprite::Spawn`, `CSprite::Use`, `CSprite::InputShowSprite` (0x1042f0a0), `CSprite::InputToggleSprite` (0x1042f0c0), `CSprite::InputTurnOn` (0x1042f110, a plain call to TurnOn), and three not walked here: `FUN_1042ea40` (sprite factory: `CreateEntityByName("env_sprite")`, SetSolid(0), `SetMoveType(9,0)`, TurnOn when its flag argument is set), `FUN_1042eb80`, `FUN_10101a20`.
- **Arms, retail order.**
  1. `m_fEffects (0x19c) &= ~0x40` (EF_NODRAW cleared; asm `1042ef79`–`1042ef87`, `AND AL,0xbf`). Unconditional.
  2. Schedule test `S = (m_flSpriteFramerate (0x458) != 0.0f AND (double)m_flMaxFrame (0x478) > 1.0) OR (m_spawnflags (0x204) & 2) != 0`.
     - 0.0f at 0x104454c4 (decoded). **K is the double at 0x10449280 = 1.0** (decoded; the first pass guessed 0.0). A sprite with 2 frames (`m_flMaxFrame` = 1.0) does not schedule; the smallest scheduling frame count is 3.
     - asm `1042ef73`–`1042efb0`: framerate equal to 0.0 jumps to the spawnflag test; otherwise `FCOMP double [0x10449280]` and the C3|C0 mask select "max frame strictly greater than 1.0".
  3. If `S`:
     - `ThinkSet(this, fn = 0x10011757, time = 0.0, context = NULL)` (0x10007fe5, thunk of 0x100ac4e0). Verified body: a NULL context writes only `m_pfnThink (+0x118) = fn` and returns; `time` is read only on the context path. `0x10011757` is a thunk (`jmp 0x1042eca0`): the stored pointer is the thunk address, the body is `AnimateThink` (below).
     - `m_flNextThink (0x17c) = gpGlobals->curtime` (`DAT_1070b228 + 0xc`).
     - `m_flLastTime (0x474) = curtime`.
  4. Always: `m_flFrame (0x45c) = 0`.
  5. Always: `ForceTransmit` tail jump: writes `+0x90 = curtime + 1.0f` (0x104454c0 = 1.0f). `CBaseEntity::ShouldTransmit` (0x100ab020, asm `100ab090`) reads it: a transmit-until stamp, networking only (replaced by Unreal replication).
- **AnimateThink body (0x1042eca0, the think TurnOn installs).** `AnimateFrame(this, (curtime - m_flLastTime) * m_flSpriteFramerate)`; then `m_flNextThink = curtime`; `m_flLastTime = curtime`. The dt handed to AnimateFrame already carries the framerate.
- **AnimateFrame body (0x1042ee50, `RET 4`, one float argument `df`).** `m_flFrame += df`. Note the two thresholds differ: TurnOn schedules at `max > 1.0`, AnimateFrame wraps at `max > 0.0`.
- **Writes.** `m_fEffects`; if `S`: `m_pfnThink`, `m_flNextThink`, `m_flLastTime`; always `m_flFrame` and `+0x90` (transmit stamp). No entity I/O, no sound.
- **Callees.** `CBaseEntity::ThinkSet` 0x10007fe5 (L0). `CBaseEntity::ForceTransmit` 0x1000e859 -> 0x1009d1e0 (networking).
- **Returns.** `void` on every path.
- **Port today.** `Source/ElysiumUE/Private/Substrate/ElysiumEnvSprite.cpp:34` is `TurnOn() { bOn = true; Publish(); }`.
  - Divergence: no `m_fEffects` word and no NODRAW bit. No schedule test. No think pointer, next-think, or last-time stamp. No frame reset.
  - Visibility restoration is present: `Publish()` reaches `SetBakedSpriteVisible` (see the Input walks).
  - The port cites this address at `ElysiumEnvSprite.cpp:4-5`.

     - If type != 2: `Msg("Setting CSprite to non-sprite model %s")`.
     - Then the base set via thunk 0x10006e83 -> `FUN_101cf4a0`: a non-empty name only. ## 0x1042f030 CSprite::Use (63 B)

- **Signature.** `void __thiscall(this, activator, caller, int useType, value)`, `RET 0x10` (four stack words). `useType` is the third. Reached through vslot 173 (`CSprite#173`); direct caller is thunk 0x100121e8 (`jmp 0x1042f030`).
- **Arms, retail order.**
  1. `state = (m_fEffects != 0x40)` (`CMP [ESI+0x19c],0x40; SETNZ`). This is an exact compare: any bit beyond 0x40 counts as on.
  2. `ok = CBaseEntity::ShouldToggle(this, useType, state)` (thunk 0x100076a3 -> 0x100a98f0).
  3. If `!ok`: return.
  4. If `state` (on): `TurnOff` (thunk 0x10010dde). Else: `TurnOn` (thunk 0x1000c3ce).
- **ShouldToggle body (0x100a98f0), verified.** Returns 0 only when `useType` is not 2 or 3 AND either (`state == 0` AND `useType == 0`) or (`state != 0` AND `useType == 1`). Otherwise returns 1. The enum is USE_OFF=0, USE_ON=1, USE_SET=2, USE_TOGGLE=3 (integers from the body; the names are Source's USE_TYPE).
- **Decision table.** OFF on->off. OFF off->no-op. ON off->on. ON on->no-op. TOGGLE and SET flip.
- **Writes.** None directly. Effects happen through TurnOn or TurnOff.
- **Returns.** `void`.
- **Port today.** `ElysiumEnvSprite.cpp` has no `Use` override. The base `virtual void Use(const FElysiumEntityHandle& Activator) {}` (`Source/ElysiumUE/Public/ElysiumEntity.h:348`) is empty and carries no `useType`; `ShouldToggle` does not exist anywhere in `Source/`.
  - Divergence: no USE_TYPE dispatch, no ShouldToggle, and no exact effects compare.
