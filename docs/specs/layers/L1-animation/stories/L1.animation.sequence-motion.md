# Derive movement from sequence motion

Layer L1 · `L1.animation.sequence-motion` · size M · 3 rows, 814 bytes of retail code

**Goal.** At 0x1008fab0, derive movement yaw from sequence linear motion; at 0x10094870, rotate that yaw by entity facing and scale by retail ground speed. At 0x10095e50, return base velocity for physics or airborne bodies and sequence-derived linear and angular velocity for grounded animation.

**Order.** GetGroundSpeedVelocity calls GetSequenceMoveYaw, and its ground-speed input is written by StudioFrameAdvance.

**Waits for** (lower-layer rows still open): `0x100ad1a0` GetVelocity
