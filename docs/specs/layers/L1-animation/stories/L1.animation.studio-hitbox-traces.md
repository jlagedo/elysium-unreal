# Build gameplay bones and trace studio hitboxes

Layer L1 · `L1.animation.studio-hitbox-traces` · size L · 11 rows, 4708 bytes of retail code

**Goal.** At 0x10095fe0, calculate sequence pose, pose adjustments, and controllers; 0x10092b50 builds requested-mask bone matrices and 0x10095460 caches them. The 0x100c4a40, 0x100c4d50, 0x100c5020, and 0x10240cb0 helpers perform studio hitbox sweeps and clips; 0x10095a20 and 0x100956e0 apply hitbox and collision results, with 0x10096b50 and 0x10097000 mapping active-set hitboxes to bones.

**Order.** The clip helpers and skeleton evaluation feed SetupBones, the cache, hitbox tests, and finally TestCollision.
