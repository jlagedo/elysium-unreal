# Resolve bone transforms and attachment endpoints

Layer L1 · `L1.animation.bone-attachments` · size L · 6 rows, 1530 bytes of retail code

**Goal.** At 0x100927f0, return cached world bones or the entity frame and apply the retail follow-movement merge. At 0x10093000 and 0x100c6520, resolve indexed attachments and named bones; 0x1019e740 and 0x1019e7d0 resolve beam endpoints, while 0x101d1530 applies an attachment or entity transform to its target.

**Order.** GetBoneTransform calls GetBoneCache; attachment and endpoint composition uses the model's bone and attachment data.
