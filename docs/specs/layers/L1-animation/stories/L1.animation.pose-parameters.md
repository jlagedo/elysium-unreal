# Read and write indexed pose parameters

Layer L1 · `L1.animation.pose-parameters` · size M · 4 rows, 661 bytes of retail code

**Goal.** At 0x100c73b0, resolve one of 24 pose descriptors locally or through included-model mappings. At 0x10091fe0 and 0x10091f10, normalize indexed and named writes; at 0x10092190, convert normalized stored state back through its descriptor.

**Order.** The setters and getter depend on the active model's local or included pose descriptors.

## Rows

- `0x100c73b0` Global::FUN_100c73b0 (159 B, 108 maps, open) — Resolve a pose descriptor for indices 0–23, first locally and then recursively through included-model index mappings. Port lacks: The kernel exposes no studio pose descriptors or included-model pose mappings. Lookup refuses and the looping setter explicitly lacks descriptor inputs.
- `0x10091fe0` CBaseAnimating::SetPoseParameter02 (179 B, 108 maps, open) — Resolve the model's pose descriptor, normalize the supplied value into m_flPoseParameter[index], and return the adjusted value; preserve input on invalid model/index. Port lacks: The indexed setter returns zero without reading descriptors or storing normalized pose state. The combat-character overload falls through to this stub.
- `0x10091f10` CBaseAnimating::SetPoseParameter01 (147 B, 108 maps, open) — Look up a pose parameter by name and dispatch its value to the virtual indexed setter. Port lacks: The named base setter is a stub returning zero. Pose-parameter name lookup also returns -1; separate combat-character write recording does not implement this dispatch.
- `0x10092190` CBaseAnimating::GetPoseParameter02 (176 B, 108 maps, open) — Read normalized pose state by index and convert it through the model's pose descriptor into a parameter value. Port lacks: A move_yaw-specific reader returns the last recorded raw named write. It does not implement indexed access or descriptor-based conversion of normalized pose state.
