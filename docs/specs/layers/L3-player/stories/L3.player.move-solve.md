# Player movement collision and velocity

Layer L3 · `L3.player.move-solve` · size M · 5 rows, 1182 bytes of retail code

**Goal.** Reproduce constraint speed scaling, velocity scrubbing, half-step gravity, hull tracing, and plane clipping from 0x1011ef20, 0x10004ebc, 0x10123e20, 0x10123f40, and 0x10124120.

**Order.** These are movement primitives used by the movement modes and command driver.

## Rows

- `0x1011ef20` Global::ComputeConstraintSpeedFactor (417 B, 108 maps, open)
- `0x10004ebc` Global::FUN_10004ebc (5 B, 108 maps, partial) — Scrub non-finite movement origin/velocity components and clamp each velocity component to sv_maxvelocity. Port lacks: Velocity sanitization and per-component clamping are carried. The matching non-finite origin scrub is missing; diagnostic messages are debug output.
- `0x10123e20` Global::FUN_10123e20 (220 B, 108 maps, partial) — Apply guarded full-step gravity and vertical base velocity, clear the consumed base-velocity component, and check velocity. Port lacks: Ordinary movement applies gravity, but this fly-gravity helper's +0x2314 guard, zero-gravity-scale fallback, vertical base-velocity impulse and clear are absent.
- `0x10123f40` Global::FUN_10123f40 (375 B, 108 maps, partial) — Sweep the player hull by a displacement, commit the trace endpoint, register a blocking contact, and return the trace. Port lacks: Swept movement and hit results exist. The retail mask/filter and trace-return contract are not reproduced explicitly, and the contact path reports only NPC bodies rather than the helper's general bloc
- `0x10124120` Global::FUN_10124120 (165 B, 108 maps, partial) — Clips velocity against a plane with an overbounce factor, zeros small output components and returns floor/wall blocking bits. Port lacks: Dot-product clipping and blocking bits exist. Retail's small-component zeroing is absent; the port instead adds repeated negative-dot reprojection.
