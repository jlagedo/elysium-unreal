# Player status bits and observer caches

Layer L3 · `L3.player.status-cache` · size L · 6 rows, 2464 bytes of retail code

**Goal.** Reproduce the +0x1ed8 status rebuild, periodic NPC/perception handle pruning and nearest-candidate scan, action and observer cache expiry, vector length estimate, and aura index at 0x10181780, 0x10181be0, 0x10175290, 0x10182810, 0x10182160, and 0x10178d10.

**Order.** The status pass reads completed grapple, Obfuscate, discipline, weapon, prayer, and animation state.
