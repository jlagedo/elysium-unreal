# Player noclip and fly or toss movement

Layer L3 · `L3.player.special-movetypes` · size S · 2 rows, 1739 bytes of retail code

**Goal.** Reproduce the noclip acceleration path and fly/toss movement with gravity, base velocity, collision resolution, and water/ground refresh at 0x10122190 and 0x10127dd0.

**Order.** These are alternate PlayerMove branches built on the shared velocity and hull primitives.
