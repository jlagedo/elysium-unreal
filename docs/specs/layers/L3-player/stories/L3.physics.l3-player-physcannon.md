# Player Hands physics-cannon interaction

Layer L3 · `L3.physics.l3-player-physcannon` · size L · 9 rows, 2326 bytes of retail code

**Goal.** Reproduce the player’s physcannon acquisition and held-object release behavior: range selection, cached eye-ray and hull search, cone fallback, eligibility, controller detach, drop notification, owner attribution, and latch clearing at 0x1040e5b0, 0x1040f550, 0x10411160, 0x10411630, 0x104116d0, 0x10411b20, 0x100143ee, 0x101895d0, and 0x104106a0.

**Order.** PlayerUse checks the physcannon path before ordinary use, and acquisition uses the player’s eye geometry. Release then consumes the held-object state and the controller’s saved physics values.
