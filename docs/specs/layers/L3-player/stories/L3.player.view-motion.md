# Player view roll and punch response

Layer L3 · `L3.player.view-motion` · size M · 5 rows, 1300 bytes of retail code

**Goal.** Reproduce signed velocity-based roll and the punch spring, then apply knockback view kick and velocity punch with retail timers and gates at 0x10124200, 0x1011f720, 0x10160a60, 0x101710b0, and 0x10171150.

**Order.** View response reads the solved movement velocity and is called from the player damage path.

## Rows

- `0x10124200` CGameMovement::vfunc6 (141 B, 108 maps, partial) — Computes signed view roll from velocity projected onto the angle-derived right vector, scaling below a speed threshold and saturating above it. Port lacks: The formula is folded into SolveViewRoll. Its added RollSpeedCm <= 0 guard returns zero, whereas retail returns signed maximum roll for that input.
- `0x1011f720` CGameMovement::vfunc7 (684 B, 108 maps, open) — Integrate punch angle and punch velocity using speed-scaled frame time, apply damping and spring feedback, and clamp angle components. Port lacks: No player punch-angle spring integration or punch-velocity state was found. NPC LocalPunchAngle storage does not implement this update.
- `0x10160a60` CBasePlayer::FUN_10160a60 (260 B, 108 maps, open) — Choose knockback view-kick strength from the prevention timer, refresh that timer when eligible, randomize three angles, and invoke ViewPunch. Port lacks: Player knockback is explicitly refused because view kick is unbuilt. Neither the prevention-time state nor the cvar-scaled random kick and ViewPunch call is implemented.
- `0x101710b0` CBasePlayer::FUN_101710b0 (117 B, 108 maps, open) — Unless disabled by the view-punch cvar, add scaled input angles to the player's local punch-velocity vector. Port lacks: The player inherits a no-op ViewPunch and has no corresponding punch-velocity accumulator or cvar gate. The player view-kick subsystem is explicitly unbuilt, not an established engine replacement.
- `0x10171150` CBasePlayer::FUN_10171150 (98 B, 108 maps, open) — Clear the player's on-ground flag and add the supplied vector to local velocity. Port lacks: The inherited VelocityPunch body is empty; no player override or folded equivalent was found.
