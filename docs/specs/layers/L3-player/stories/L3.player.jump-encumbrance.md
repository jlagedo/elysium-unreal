# Player jump input and encumbrance speed

Layer L3 · `L3.player.jump-encumbrance` · size S · 2 rows, 488 bytes of retail code

**Goal.** Reproduce the grounded pressed-button jump gates, jump animation/timestamp writes, conveyor velocity inheritance, and Strength/Encumbrance speed ratio at 0x1016a870 and 0x101e8820.

**Order.** These player rules consume the completed ground and move sample before command movement continues.

**Waits for** (lower-layer rows still open): `0x100b1ac0` CalcAbsolutePosition
