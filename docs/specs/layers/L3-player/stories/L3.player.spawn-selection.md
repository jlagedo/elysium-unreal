# Player spawn selection and placement

Layer L3 · `L3.player.spawn-selection` · size M · 4 rows, 1455 bytes of retail code

**Goal.** Reproduce cooperative and named spawn selection, last-spawn tracking, world fallback, and crouched restore overlap adjustment at 0x1034f860, 0x1016cd20, and 0x1016b750.

**Order.** Spawn selection and collision-safe placement are required by both fresh Spawn and Restore.
