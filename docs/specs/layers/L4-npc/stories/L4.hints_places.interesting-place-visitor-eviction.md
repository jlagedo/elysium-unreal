# Interesting place visitor eviction

Layer L4 · `L4.hints_places.interesting-place-visitor-eviction` · size M · 1 rows, 514 bytes of retail code

**Goal.** `InputDisable 0x102db440` calls `0x102daac0` unforced: an occupant with `INTERESTING_INTO` gets `flags2 |= 0x80000008`; every other occupant gets provenance stamped and `TaskFail(0x23)` through slot 448. The place destructor `0x102d9b10` calls it forced, bypassing the flag branch, and slot 614 resets each visitor’s think timers on both paths.

**Order.** `TaskFail` (slot 448) and `ResetThinkTimers` (slot 614) are already ported; this row has no open-row callee dependency.
