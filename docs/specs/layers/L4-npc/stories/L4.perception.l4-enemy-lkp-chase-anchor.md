# Translate the base NPC enemy chase position

Layer L4 · `L4.perception.l4-enemy-lkp-chase-anchor` · size M · 1 rows, 142 bytes of retail code

**Goal.** For `CAI_BaseNPC::TranslateEnemyChasePosition` (`0x10289f20`), NAV_FLY (`0x1027d990` returns 2) offsets the chase point by the enemy's eye-minus-origin vector and writes the NPC hull's Y width (`0x102d61b0`) as tolerance. On every other nav type, the base body writes zero tolerance and leaves the point unchanged.

**Order.** This chase consumer follows sight/memory, which supplies the enemy and last-known position.
