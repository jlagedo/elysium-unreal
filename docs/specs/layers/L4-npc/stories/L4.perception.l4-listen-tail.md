# Promote heard conditions before firing outputs

Layer L4 · `L4.perception.l4-listen-tail` · size M · 1 rows, 513 bytes of retail code

**Goal.** `CAI_BaseNPC::OnListened` (`0x1026a5e0`) clears the ten HEAR/SMELL conditions, maps each exact raw sound type to its condition, promotes due entries using `GetReactionDelay` (`0x1026a8a0`), then fires the corresponding output. The port currently fires hearing outputs inside `TickHearing` before the sensing caller copies promoted conditions into the NPC condition set.

**Order.** Retail invokes OnListened after Listen has collected sounds and after OnLooked has completed.
