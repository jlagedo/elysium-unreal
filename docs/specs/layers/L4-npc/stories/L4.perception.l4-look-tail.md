Layer L4 · `L4.perception.l4-look-tail` · size M · 1 rows, 624 bytes of retail code

**Goal.** After each Look, `CAI_BaseNPC::OnLooked` (`0x1026a2c0`) clears the six `SEE_*` conditions, skips the selected unknown, then classifies visible entities and updates enemy memory in retail order.
