# Targeted discipline table

Layer L4 · `L4.npc_kernel.targeted-discipline-table` · size M · 4 rows, 528 bytes of retail code

**Goal.** Reproduce targeted-record initialization and sequential table growth at 0x101e0520 and 0x101e0c30, indexed access with the ID -1 fallback at 0x101e11c0, and the authored interrupt-presence scan at 0x101e08d0.

**Order.** The table's aggregate interrupt flag reads hit-group records, so those records and their fallback are built first.

## Rows

- `0x101e0520` Global::FUN_101e0520 (139 B, 108 maps, partial) — Initializes a targeted-discipline record and derives its flag as 1 << (ID & 31) for IDs below 30, otherwise zero. Port lacks: FElysiumDisciplineTgt supplies empty containers and cleared configuration fields. It lacks the numeric record ID, derived 30-bit flag and retail sentinel initialization; notably retail ID -1 produces 
- `0x101e0c30` Global::FUN_101e0c30 (238 B, 108 maps, partial) — Appends a targeted-discipline table slot, grows its pointer storage and lazily constructs a record with the slot's sequential ID. Port lacks: Add appends records in order through TArray. It does not reproduce retained pointer-slot reuse or construct each record with the sequential ID and derived flag supplied by 0x101e0520.
- `0x101e11c0` Global::FUN_101e11c0 (75 B, 108 maps, open) — Returns an indexed targeted-discipline record, or a lazily initialized static record with ID -1. Port lacks: The cited lookup is explicitly seamed to a constant zero cooldown. The separate name-based discipline table does not implement this indexed accessor or its sentinel record.
- `0x101e08d0` Global::FUN_101e08d0 (76 B, 108 maps, open) — Scans a discipline's hit groups and sets record byte +0x34 when any OnInterruptSchedule HitInfo is authored; always returns true. Port lacks: OnInterruptSchedule is explicitly omitted by the parser. No corresponding aggregate-presence flag or scan was found.
