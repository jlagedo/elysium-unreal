## Goal

GetExpressionData, IsValidExpressionIndex, and GetExpressionID are leaves for LookupExpression, which calls GetExpressionID. The story: Retail `IsValidExpressionIndex` (`0x10104ff0`), `GetExpressionData` (`0x101051b0`), and `GetExpressionID` (`0x10105270`) validate indices, return 400-byte rows, and normalize names into packed IDs. `LookupExpression` (`0x10105870`) uses that ID to return the first matching row index or `-1`.
