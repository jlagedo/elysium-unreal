## Goal

The record constructor, sequential append, indexed access, and child-record scan form one table contract. The story: Reproduce targeted-record initialization and sequential table growth at 0x101e0520 and 0x101e0c30, indexed access with the ID -1 fallback at 0x101e11c0, and the authored interrupt-presence scan at 0x101e08d0.
