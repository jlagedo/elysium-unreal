## Goal

Scene time, controller fallback, and flex track sampling feed one choreography animation result. The story: Reproduce scene time at 0x1007dfa0, case-insensitive controller lookup and zero-on-miss at 0x100b5d10, and combo-side flex sampling at 0x10074610.

## The retail functions (read each body before writing: `vtmb_code <address>`)

- `0x1007dfa0` Global::FUN_1007dfa0 (4 B, 108 maps, partial) — Returns the choreography scene's current-time float at +0x7c. Port lacks: ScenePlayer exposes a real current-time getter, but the NPC-facing SceneTimeOf returns zero and explicitly does not reach that clock. Gesture wind-back therefore lacks the retail input.
- `0x100b5d10` Global::LookupFlexController (70 B, 108 maps, partial) — Scans flex-controller names case-insensitively and returns the first matching index, returning zero on a miss. Port lacks: FindController carries the case-insensitive linear search, but returns INDEX_NONE on a miss instead of retail's controller-zero fallback. The kernel helper was removed.
- `0x10074610` Global::FUN_10074610 (159 B, 108 maps, open) — Samples a flex track and scales its value by the selected combo side's balance around 0.5. Port lacks: The sole caller, AddFlexAnimation, is empty. No corresponding track sampler or combo-side scaling was found. Retail assembly supplies floating-point calculations omitted by the packet's decompile.
